# Yb³⁺–Pr³⁺ Photon Avalanche

An interactive research demonstration of spatial kinetic Monte Carlo dynamics, energy-transfer pathways and homogeneous rate-equation build-up.

The simulation runs locally in the visitor's browser. The recorded population plot contains one selected scan with 30 original intensity samples; it does not change with the live simulation controls.

This directory contains the browser demonstration and its required data only. Full research results, source code and development history are not publicly available.
